# 🤖 Dan API (api.hpdev.name.vn)

Backend Core API cho hệ sinh thái Đần AI với kiến trúc chuẩn **OOP & SOLID** trong ExpressJS.

## 🌿 Nhánh Git: `api`
* Nhánh độc lập, **không merge vào `main`**.
* Triển khai tự động tới: `api.hpdev.name.vn:3000`

## 🚀 Khởi chạy Local:
```bash
npm install
npm start
# Chạy Unit Tests:
npm test
```
